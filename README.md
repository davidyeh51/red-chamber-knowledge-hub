## 📌 核心定位與設計宗旨

本專案打破傳統文學考據或八卦索隱的刻板讀法，嚴格依據**中央美院人文學院古典文學學者 董梅老師《講透紅樓夢》課程（34 講精研筆記與 300+ 分鐘原聲講座）**，運用**麥肯錫金字塔原理（Pyramid Principle）與 MECE 架構**，重新提煉結構化知識：

1. **結論先行（Action Titles）**：每頁簡報標題即為該主題之實質行動結論，拒絕空泛分類詞。
2. **三核心要素剖析**：
   - 📌 **人生核心難題／矛盾**：指出該篇要解決的現代人真實生活或職場卡點。
   - 💡 **三大關鍵洞察（MECE）**：提供 1–3 個獨特觀點、反直覺反常識之處與文本實證。
   - 🌿 **人文素養修煉 ✕ 現代落地指南**：提供 3 條具體可執行的情商心法與生活實踐清單。
3. **全域與頁內即時關鍵字檢索引擎（34 講全索引）**：
   - 支援模糊比對、多關鍵字交集、標籤快篩與匹配詞動態高亮（`<mark>`），快捷鍵 <kbd>Ctrl</kbd> + <kbd>K</kbd> 一鍵喚起。
4. **16:9 麥肯錫顧問簡報系統**：
   - 支援全螢幕簡報模式、麥肯錫三段式講者備忘錄抽屜（<kbd>N</kbd>）、投影片總覽導航（<kbd>G</kbd>）與純淨 16:9 列印 PDF 導出（<kbd>P</kbd>）。

## ⌨️ 簡報鍵盤快捷鍵一覽

在任何簡報頁面中，使用者可使用以下鍵盤快捷鍵進行高效演練或演講：

| 快捷鍵 | 功能說明 | 應用情境 |
| :---: | :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> | 下一頁投影片 | 循序講解培訓內容 |
| <kbd>←</kbd> / <kbd>Backspace</kbd> | 上一頁投影片 | 倒退複習關鍵重點 |
| <kbd>N</kbd> | **呼出 / 關閉 講者備忘錄抽屜 (Speaker Notes)** | 查看麥肯錫三段式演講稿（破題、論據、落地） |
| <kbd>G</kbd> | **投影片總覽網格導航 (Grid Overview)** | 快速檢視全 34 頁縮圖並跳轉至指定章節 |
| <kbd>F</kbd> | **切換全螢幕模式 (Fullscreen)** | 投影教學、沙龍分享、會議室演講 |
| <kbd>P</kbd> | **一鍵列印 / 匯出 16:9 顧問 PDF 備忘錄** | 自動隱藏工具列，以純淨 16:9 比例匯出 |
| <kbd>Esc</kbd> | 關閉抽屜或關閉總覽網格 | 返回正常簡報閱讀模式 |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | 聚焦全域搜尋框 (首頁) | 快速啟動全庫搜尋 |

## 🛠️ 預留擴充架構 (Data-Driven Architecture)

本知識庫具備高度模組化與可擴充性：

```
red-chamber-knowledge-hub/
├── index.html                   # 知識庫主頁（數據儀表板 + 全域搜尋 + 模組卡片）
├── presentation.html            # 16:9 麥肯錫結構化簡報系統
├── data/
│   ├── courses.json             # 核心知識庫資料結構 (34 講完整資料)
│   └── search-index.json        # 毫秒級全域關鍵字搜尋索引
├── assets/
│   ├── css/
│   │   ├── style.css            # 麥肯錫入口首頁樣式
│   │   └── deck.css             # 16:9 簡報樣式與列印樣式
│   └── js/
│       ├── search.js            # 全文檢索引擎、模糊比對與高亮模組
│       └── deck.js              # 簡報互動控制器 (鍵盤/講稿/總覽)
└── docs/
    └── EXPANSION.md             # 擴充 SOP 指南（如何三步驟新增講義與簡報）
```

詳細擴充步驟請參閱 [`docs/EXPANSION.md`](docs/EXPANSION.md)。
